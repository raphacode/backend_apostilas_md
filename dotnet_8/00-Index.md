# Apostila Completa de Backend com C#

> Uma jornada do **absoluto zero** até a construção de **APIs profissionais** com C# e ASP.NET Core.
> Material didático para alunos iniciantes que **nunca programaram**.

---

## Como estudar esta apostila

1. **Leia em ordem.** Cada capítulo depende do anterior.
2. **Digite os exemplos.** Não copie e cole — digitar fixa o aprendizado.
3. **Faça os exercícios.** Eles estão no fim de cada capítulo.
4. **Não tenha pressa.** Backend é uma maratona, não corrida.
5. **Releia.** Conceitos novos só "caem a ficha" depois da segunda leitura.

## O que você vai aprender

- Pensar como um programador.
- Dominar a sintaxe e os recursos da linguagem **C#**.
- Entender profundamente **Orientação a Objetos**.
- Trabalhar com **coleções** de forma correta.
- Construir **APIs REST** profissionais com **ASP.NET Core**.
- Organizar projetos backend de forma **limpa e escalável**.
- Escrever **código de qualidade**, fácil de manter.
- Persistir dados em **PostgreSQL** com **Entity Framework Core**.
- Implementar **autenticação JWT** profissional.
- Construir, do zero, uma **API completa (Movies.API)** com banco, autenticação e Swagger.

## Pré-requisitos

**Nenhum.** Sério. Esta apostila parte do zero absoluto. Tudo que você precisa é:

- Paciência para praticar.

As ferramentas serão instaladas no Capítulo 2.
