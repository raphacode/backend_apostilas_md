# Tipos de dados

```sql
VARCHAR(255)
TEXT
CHAR(2)
```

## Inteiros
```sql
INTEGER
BIGINT
BIGSERIAL
```

## Decimal exato
```sql
NUMERIC(10,2)
```

## Booleano
```sql
BOOLEAN
```

## Data/hora
```sql
DATE
TIMESTAMP
TIMESTAMPTZ
```
