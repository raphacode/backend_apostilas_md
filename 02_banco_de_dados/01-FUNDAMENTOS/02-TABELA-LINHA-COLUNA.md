# Tabela, linha, coluna e registro

| id_cliente | nome | email |
|---:|---|---|
| 1 | Ana | ana@email.com |
| 2 | Bruno | bruno@email.com |

- **Tabela**: `clientes`.
- **Coluna**: `id_cliente`, `nome`, `email`.
- **Linha/registro**: um cliente completo.
- **Campo**: o valor de uma coluna em uma linha.

A estrutura diz **como** os dados podem ser armazenados; os registros são os dados reais.
