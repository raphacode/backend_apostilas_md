# Modelagem relacional

Modelagem transforma regras reais em tabelas e relacionamentos.

Exemplo:

```text
Cliente faz Pedido
Pedido possui Produtos
Fornecedor fornece Produtos
```

Objetivos:
- evitar repetição;
- preservar integridade;
- facilitar consultas;
- representar regras reais.
